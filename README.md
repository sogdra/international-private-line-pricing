## IPLC、IEPL、IXP、CN2：这些词到底差在哪

搜国际专线报价时你会反复碰到这几个词，但很多页面讲不清楚它们差别。这里按"你实际会感受到什么"来讲。

**IPLC（International Private Leased Circuit，国际私有租用线路）**：点对点物理专线，两端之间是一条封闭的"水管"，数据不出这条管道，不经过公网。你的流量从上海入口进去，从香港/日本/美国出口出来，中间没有任何公网跳转。好处是延迟稳定、不被公网拥塞影响、隐匿性好；代价是成本高，因为整条线是你（或服务商）独占的。

**IEPL（Ethernet Private Line，以太网点对点专线）**：和 IPLC 定位类似，也是独享的点对点线路，但底层走的是以太网协议，通常用来替代传统 SDH 电路，带宽调整更灵活。对使用者来说，体感和 IPLC 接近——都是"独享、稳定、低延迟"，主要差异在于底层技术和计费灵活度，通常不需要纠结两者选谁。

**IXP（Internet Exchange Point，互联网交换中心）**：严格说 IXP 不是一条专线，而是不同网络之间互联互通的节点。MKCloud 的"IXP 专线"指的是通过 IXP 优化路由出口到香港/日本/美国，走的是优化后的公网路径，而不是完全物理隔离的管道。**这是它能做到 ¥158/月 而纯 IPLC 起步要 ¥288/月 的核心原因——共享的优化路由，成本远低于物理独享。**

**CN2（ChinaNet Next Carrying Network，电信下一代承载网）**：中国电信的精品骨干网，走 CN2 的国际出口拥塞概率远低于普通 163 骨干网。MKCloud 的"上海 CN2"产品入口是上海动态联通，出口直接对接上海电信 CN2，适合对"从中国出口这一段"质量要求极高的场景。它 ¥4500/月 的起售价也说明了 CN2 出口资源的稀缺性——这条产品线本质上不是给个人用户的。

一句话总结：**预算紧、对延迟要求没那么极端 → IXP；要物理隔离和稳定低延迟 → IPLC/IEPL；要电信精品网出口 → CN2，但预算要按企业级准备。**

## 价格怎么读：为什么"起售价"和最终账单可能差好几倍

这是搜报价时最容易踩的坑。表格里的"¥358/月起"只是门槛价，最终费用取决于三个变量：

**变量一：计费模式——流量计费 vs 独享带宽计费**

MKCloud 的 IPLC 和 IXP 产品都提供两种计费方式：

- **流量计费**：按实际使用流量计费，适合流量波动大、不是持续跑满的场景，比如每天只在固定时段跑备份或同步数据。
- **独享带宽计费**：按独享的带宽规格计费，带宽随时可用、不按用量额外收费，适合长时间稳定占用带宽的场景，比如企业 VPN 网关、持续的数据同步。

两者没有绝对优劣，但如果你预期每天都要稳定占用 50Mbps 以上的带宽，独享带宽通常更划算；反过来，偶尔用一下的话，流量计费能把成本压得很低。

**变量二：带宽规格**

起售价对应的带宽规格官网未直接标注，但所有套餐均标注"所有配置均可定制"，这意味着带宽是需要和客服确认报价的核心参数。一般来说，独享带宽翻倍，月租也会相应上浮。

**变量三：部署方式——云服务器 vs 独立物理服务器**

所有套餐都支持两种部署选择。云服务器成本低、开通快，够用；独立物理服务器性能更强、资源完全独占，但月租会更高。企业客户如果有合规或性能要求，通常会选物理服务器，这部分也会推高最终报价。

> 所以如果你打电话/发工单询价，这三个参数先想清楚：要哪种计费方式、要多少带宽、要云还是物理机。少问一个，来回沟通的成本都是你自己的。

## 延迟数字是什么意思：选线路前先看这张延迟参考

MKCloud 官网对每条 IPLC 线路都标注了"端内延迟"——这是指数据从入口进、出口出，在这条专线内部传输产生的延迟，不含你本机到入口机房、以及出口到最终目标服务器的延迟。这个数字是横向对比线路质量的核心指标：

- **广港 IEPL：1~2ms**。这个数字很夸张但合理——广州到香港物理距离非常近，光纤直连的情况下 1~2ms 是理论最优值。适合对延迟极度敏感的场景。
- **沪港 IPLC：21ms**。上海到香港的物理距离决定了它不可能比广港更低，21ms 已经很接近物理极限。
- **沪日 IPLC：25~28ms**。上海到东京的海底光缆长度决定了这个区间，属于正常水平。
- **沪美 IPLC：124~134ms**。跨太平洋的光缆物理延迟就在 120ms 上下，这是绕不开的物理规律，不是线路质量问题。

> 一个判断标准：如果你主要访问的目标服务器在香港，选沪美线路再"加速"也解决不了问题，因为跨太平洋那段物理延迟已经写死了。选线路之前，先想清楚你要连的服务器到底在哪。

IXP 专线（深港/沪日/沪港/沪美）官网未标注端内延迟，这符合它的定位——优化公网路由本身就存在波动，不像 IPLC/IEPL 那样给出确定值。如果你需要写入 SLA 的延迟承诺，应该选 IPLC 或 IEPL。

## 按场景对号入座：你到底需要哪条线

**场景一：跨境办公 / 远程访问企业内网**

典型需求：少数几个人稳定访问海外公司内网、ERP、Git 仓库。流量不大但要求稳定不掉线。
**推荐：沪港 IPLC（¥288/月起）或 IXP 专线（¥158/月起）**。如果只是 2-3 人轻度使用，IXP 性价比更高；如果要求绝对稳定、写入企业 SLA，上沪港 IPLC。

**场景二：跨境电商 / 海外业务系统对接**

典型需求：国内团队访问海外店铺后台、海外客户访问国内展示系统，对稳定性和 IP 独享性有要求。
**推荐：广港 IEPL（¥358/月起）**。广港线路 1~2ms 的端内延迟 + 八线动态 BGP 入口，能兼容不同运营商的用户接入，适合客户来源复杂的场景。所有套餐都包含独享独立 IPv4，这对需要固定 IP 白名单对接的业务是刚需。

**场景三：金融交易 / 量化对延迟敏感**

典型需求：国内交易指令到海外交易所的路径延迟要尽量低且稳定。
**推荐：沪港 IPLC（21ms）或沪日 IPLC（25~28ms）**，取决于目标交易所位置。官网标注 7×24h 技术服务，这类场景出问题需要即时响应，不能只靠工单。部分有省级白名单限制的产品仅支持选定省份使用（可切换），这对需要指定出口省份的合规场景反而是加分项。

**场景四：跨国文件传输 / 数据同步**

典型需求：两地之间定时同步大文件，比如设计源文件、备份数据库。
**推荐：IXP 专线（¥158/月起）配合流量计费**。如果同步发生在固定时段，流量计费比独享带宽便宜得多；需要持续大带宽传输则改用独享带宽计费。

**场景五：出口质量要求极高的合规场景**

典型需求：从中国大陆出口的这段网络质量必须是电信精品网级别。
**推荐：上海 CN2（¥4500/月起）**。这条产品线价格远高于其他产品，适合的是企业级合规需求，不是个人或小团队的性价比选择。

> 如果你的需求不在这五类里，但涉及"国内到海外"的稳定连接，更实际的做法是直接联系客服描述场景，让他们推荐线路类型——MKCloud 所有套餐都支持定制，硬套套餐反而不划算。
